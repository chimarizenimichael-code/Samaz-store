# SAMAZ Store - Kitchen Ware & Electronics

A modern, responsive e-commerce website built with React and Tailwind CSS for SAMAZ Kitchen Ware & Electronics.

## Features

✨ **Modern Design** - Sleek dark theme with smooth animations
📱 **Responsive** - Works perfectly on desktop, tablet, and mobile
🛍️ **Product Showcase** - Featured products with pricing
📞 **Contact Form** - Customer inquiries and support
🎨 **Tailwind CSS** - Utility-first CSS framework
⚡ **Vite** - Fast development and optimized production builds

## Getting Started

### Installation

```bash
git clone https://github.com/chimarizenimichael-code/samaz-store.git
cd samaz-store
npm install
```

### Development

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

## Deployment

The site automatically deploys to GitHub Pages: https://chimarizenimichael-code.github.io/samaz-store

- React 18
